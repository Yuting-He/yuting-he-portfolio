# GridScout 硬件传感与异常证据方案

日期：2026-10-24。状态：硬件设计建议，未完成器件选型、整机集成或现场验证。

本文件回答：需要哪些传感器、获得什么信息、支持识别哪些异常、如何安装，以及如何满足新增载荷限制。它补充 [实时状态孪生与决策网络设计稿](DIGITAL_TWIN_DECISION_PLAN.md)，不改动当前程序。

## 1. 推荐配置与证据状态

首版沿用“强风下的线路机械异常核查”主案例：**已有温度、振动、电压、倾角 + 复用 RGB 相机 + 独立环境温湿度 + 外部天气/运行背景**。热像、几何测距和烟气组件按任务增配，不默认全部装到每台设备上。

| 信息 | 当前证据状态 | 设计处理 |
| --- | --- | --- |
| 温度、振动、电压、倾角；实时回传 | 项目设计稿记录为用户已确认；测量对象、精度和接口未知 | 按已知类别设计，字段语义仍需确认 |
| 机重 3.8 kg、新增不超过 250 g | 项目设计稿记录为用户提供 | 按每台完整新增组件合计 ≤250 g 预算 |
| RGB Camera、Current Measurements | Nomadic 当前官网列出的平台能力 | 优先核实本次设备及接口是否开放，不当作挑战已提供的数据 |
| 弧垂、净空、覆冰厚度 | 官网描述的应用能力 | 需要本次可用输出、测量方法和精度，不能由原始倾角自行宣称已获得 |
| 相机、风速、负荷、精确 3D | 本次数据访问情况未确认 | 缺失显示 unknown；需要时使用明确标注的合成演示数据 |

官网与本次设备的可用数据是两个不同层次。尤其应先确认官网所述电流是否就是本次已提及的“电压”，或它们是两个独立通道。[Nomadic 平台与传感器说明](https://www.nomadicdrone.com/nomadic-drone)

Nomadic 是可停驻在线路上的移动传感平台。首版主要在稳定停驻时测量线路状态；飞行是转移和获取特定视角的方式。测量范围必须跟随实际安装点和相机视野，不把五个点的实时回传描述成全网直接实时观测。[Nomadic 工作方式](https://www.nomadicdrone.com/)

## 2. 按图中的硬件类别组织

| 类别与建议 | 直接采集什么 | 提取什么特征 | 支持判断的异常 | 主要边界 |
| --- | --- | --- | --- | --- |
| **RGB 相机：优先复用；360°可选** | 目标图像/短视频、时间、相机姿态与资产位置 | 异物位置、可见裂损/断股、植被接近、烟羽、可见覆冰、前后变化 | 可见机械损伤、树枝/异物接触疑点、烟火或覆冰疑点 | 单视角投影重叠不证明接触；未看到不等于不存在；细小缺陷取决于目标像素、清晰度与遮挡 |
| **电压或带电状态传感：已有，先确认语义** | 校准后的电压，或仅为电场/带电状态代理 | 状态突变、持续失压、与开关记录一致性 | 带电状态异常或需要核对的运行事件 | 断电不等于导线损坏；低代理信号也可能是姿态/测量问题；不能推出可充电功率 |
| **线路电流：官网列出，优先争取复用** | 同一资产/相别的电流有效值；若接口支持再取波形 | 负荷变化、持续高电流、异常暂态；结合已知额定条件分析 | 过载疑点、热异常解释、与保护事件一致性 | 电流偏大本身不等于过载；没有明确电气关联的变电站数据不能当成本段电流；小电流不排除异物接触 |
| **导线温度：已有，确认是接触温度还是其他温度** | 安装点的导线表面温度 | 温升速度、持续时间、相对环境及条件正常基线的温度残差 | 局部或持续热异常疑点 | 一个点不能代表整段或远端接头；负荷、日照、风、安装接触及充电热源都可能影响读数 |
| **可测温红外热像：热异常任务可选** | 目标区域辐射测温图、测量参数与目标位置 | 热点位置/范围、邻近同类目标温差、随时间变化 | 接头或金具局部过热、可见范围内的热源/火点疑点 | 必须是测温型号；金属反射、发射率、视角、目标像素不足会误导；热点不直接给出故障原因 |
| **三轴加速度/振动：已有** | 与导线机械耦合的加速度波形，或有定义的振动特征 | RMS、峰值、频带能量、主频、持续性 | 异常振动、舞动疑点、机械状态变化 | 旋翼/机体自身振动不能直接当成线路振动；设备质量、夹持和位置改变都影响基线 |
| **倾角/IMU：已有** | 重力参考下的姿态、相对安装基准的角度 | 持续偏移、摆动幅度、风后能否恢复 | 异常机械位移、夹持偏移或导线形态变化疑点 | 单个机身倾角不能直接确认杆塔倾斜或精确弧垂；动态加速度与安装变化需要排查 |
| **高度/测距：精确净空任务可选** | GNSS/RTK 位置及解状态、经验证的激光测距/点云，或标定的多视角图像 | 导线相对地面/树冠距离、几何变化及不确定度 | 净空减少、弧垂变化、植被距离不足疑点 | 飞控高度不是导线最低点净空；单点测距不是全跨最小净空；薄导线目标命中、测距范围及坐标基准必须验证 |
| **烟气/颗粒物：野火任务可选，首版后置** | 局部颗粒物浓度；按任务选择 CO 等气体通道 | 浓度变化、持续性、与风向/烟羽/热像的一致性 | 附近烟气暴露或火情疑点 | 烟必须到达采样口；粉尘、雾滴和其他排放可能干扰；无烟读数不能排除远处火情 |
| **独立环境温湿度：优先新增** | 空气温度、相对湿度；可计算露点作为背景 | 导线与空气温差、湿冷条件、环境变化 | 解释正常温升、支持覆冰/凝露风险评估、减少误报 | 不测导线温度；低温或高湿不能单独确认覆冰；需要隔离日照、机体与充电热源 |
| **位置、设备模式与自检：优先复用** | 资产 ID、位置/定位质量、飞行/停驻/夹持/充电状态、供电和通信状态 | 数据新鲜度、模式切换、漂移/饱和/缺失、安装版本 | 区分资产异常、设备异常和观测不可用 | 这是可信判断的必要背景；失联不填零，不继续显示正常 |

温湿度可评估 SHT4x 类低功耗元件，但元件规格不代表集成后精度；应优先做独立、通风且热隔离的测量位置。[Sensirion 集成设计指南](https://sensirion.com/resource/user_guide/sht/design_in)

热像可从轻量辐射测温核心评估。FLIR 的指南强调目标覆盖像素、发射率、背景反射和模块热稳定性；仅有彩色热图不足以产生可信温度。远距离细导线尤其需要验证光学分辨能力。[FLIR 测温与集成指南](https://oem.flir.com/learn/thermal-integration-made-easy/radiometry-with-lepton/)

## 3. 对原图的五处关键修正

### Camera (360 degree)

把要求写成“**目标可辨识的 RGB 图像与可追溯视角**”。360°适合周边态势和烟羽观察，但在相同总像素下，广覆盖会分摊目标的像素。线路细节核查更需要合适焦距、清晰度、视角和必要的多视角；首版不因追求360°而重复采购相机。

### Voltage / Current → Resistance → foreign objects

这条推断不能直接成立。交流系统中，目标两端电压与流经目标电流的相量关系对应阻抗；阻抗的实部才是电阻。线路对地电压不是某个接头两端的电压降，普通 V/I 不能定位其接触电阻，更不能确定异物类别。[HIOKI 阻抗测量原理](https://www.hioki.com/euro-en/learning/usage/lcr-meters_1.html)

树枝接触还可能是高阻路径，电流变化小。EPRI 的实验说明某些单相树枝接触电流可不足以触发常规保护；这不应泛化为所有电压等级的固定数值。设计上采用“视觉疑点 + 电气/保护事件 + 机械/热证据”的组合，不能因没有大电流就排除接触。[EPRI 植被故障研究](https://distribution.epri.com/epri/public/oh-hazards/vegetation-faults/)

### Heat Sensors → fire / freezing

必须区分导线温度、环境温度、机体温度和远处热源。接触温度只覆盖安装点；热像才能补充视野内热点的空间信息。高温可能来自正常负荷或日照，不能单独确认火灾。

覆冰需要适当水分与温度条件。以冻雨为例，过冷水滴接触低温表面形成冰，因此温度低于零度本身只支持风险条件。结合降水/冻雨信息、可见覆冰和机械/几何变化，再判断是否有实际积冰。[NOAA 冬季降水类型](https://www.nssl.noaa.gov/education/svrwx101/winter/types/)

### Tilt / Elevation

加速度计估计倾角时依赖重力，运动加速度会造成偏差。固定安装、停驻状态和基准姿态是前提。[Analog Devices 倾角测量说明](https://www.analog.com/en/resources/app-notes/2020/07/22/16/49/an-1057.html)

GNSS 测得的是天线参考点位置，高度可能为椭球高；换算到导线点要考虑坐标基准、天线偏移与姿态。[Trimble 位置输出说明](https://receiverhelp.trimble.com/oem-gnss/help-status-position.html)

因此精确净空需要导线几何、地面/障碍物几何和测量误差共同支持。若只有本次未标定倾角，应展示“相对角度变化”；若厂商提供已验证的弧垂/净空输出，则沿用其测量定义与置信范围。

### Smoke Detector → does not work

改为“**适合特定场景，有采样位置限制**”。停驻且旋翼关闭时，局部烟气监测可以有价值；风把烟吹离设备时仍可能漏检。飞行时还要处理旋翼扰动。实测研究表明采样口布置能显著改变无人机颗粒物测量质量，不能把某篇研究的安装距离直接当成本机通用规则。[无人机颗粒物采样实验](https://www.nature.com/articles/s44407-025-00044-3)

首版以 RGB/可选热像承担远处可见火情核查；只有明确选择野火任务，再评估专用颗粒物/气体采样组件。

## 4. 让传感器组合回答具体异常

下表是待验证的证据设计，不是已经训练或校准的故障分类器。

| 场景 | 支持异常的组合 | 需要保留的正常/测量解释 | 合理输出 |
| --- | --- | --- | --- |
| 强风下正常摆动 | 风增强时振动/摆动增加，风减弱后恢复，符合该安装位置基线 | 线路仍可能接近工程限值，基线正常不等于运行安全 | 持续监测，并单列工程限值检查 |
| 持续机械异常 | 风减弱后倾角偏移或异常频带持续，图像显示对应变化 | 夹持松动、安装改变、局部风与区域天气不一致 | 机械异常疑点，补测/视觉复核或人工升级 |
| 树枝/异物接触 | 多视角图像显示接近或接触，伴随机械变化或电气事件 | 透视重叠；相邻相/相邻线路事件；无大电流不能排除 | 标注位置及证据充分度，安排核查 |
| 热异常 | 温度偏离天气/负荷条件基线，热像有对应局部热点 | 正常负荷、日照、弱风、反射、接触测温问题；负荷未知 | 热异常疑点；负荷未知时保留原因不确定性 |
| 覆冰 | 湿冷/冻雨背景 + 可见覆冰，或与覆冰相符的机械/几何变化 | 降温收缩、风摆、张力变化、镜头结露；不能凭频率变化直接算冰厚 | 覆冰风险/疑似积冰；只有经标定测量才输出冰厚 |
| 净空不足 | 已标定测距/3D 确认导线与地物接近，且考虑误差和资产限值 | 定位基准错配、测距命中背景、单点遗漏最低处 | 带误差范围的净空判断；数据不足显示待测 |
| 烟火 | 烟羽或热点随时间持续，若采样口处于烟羽再结合气体/颗粒物 | 云雾、粉尘、工业排放、热反射 | 火情疑点及定位；紧急证据不强制等待全部通道 |
| 停电/失压 | 有效带电代理下降且运行记录一致 | 预防性停电、上游跳闸、传感失效 | 单列带电状态，损坏状态仍未知 |

原项目中的 LINE_024 属于已知预防性断电，不能用它来演示“电压降低就确认线路故障”。

## 5. 怎么装、重量怎么算

以下是功能布局建议；高压侧适配沿用平台厂商认可的接口和结构，实际接触式改装由平台方完成集成验证。普通低压开发板不能直接作为高压线路电压测量装置。

| 部件 | 安装原则 |
| --- | --- |
| 线路温度、机械传感 | 采用已验证的测温/夹持路径；机械测量需要已知耦合，不能统一加减振垫把待测线路振动滤掉；新增质量和夹持状态纳入基线 |
| RGB/热像 | 目标视野不被机臂或夹具遮挡；记录相机与设备的相对姿态；图像所需稳定措施与线路振动测量路径分别设计 |
| 环境温湿度 | 通风、防辐射、远离电池和充电电子器件热源；防护结构仍需允许空气交换，记录响应延迟 |
| 可选气体/颗粒物 | 设计可用采样口与响应时间；优先稳定停驻采样；飞行数据须有相应扰动校准 |
| 计算、供电、通信 | 优先复用平台资源；核对数据接口、峰值功耗、存储和通信带宽；高频振动在机端形成特征，事件时保存原始片段 |

延续现有设计稿的质量分配，不把元件裸重当成完整载荷重量：

| 新增项目 | 设计预算 |
| --- | ---: |
| 环境温湿度测量组件 | 20 g |
| 轻量 RGB 成像组件；已有可用相机则复用 | 80 g |
| 接口、电源转换、线束及必要处理组件 | 40 g |
| 外壳与安装结构 | 60 g |
| 工程余量 | 50 g |
| 合计上限 | **250 g** |

这是分配上限，尚不是已验证 BOM。选择热像时，应重新分配整套预算；相机复用也不自动保证剩余预算足够装热像、测距和烟气组件。整机集成还要验证重心、迎风面积、夹持、功耗、热影响、EMI 和有效测量能力。3.8 kg + 0.25 kg = 4.05 kg 仅表示质量增加，不用于线性推算续航。

首版不强制新增机载风速计；先接外部风速/阵风、降水、日照和预警，并标注局地代表性。若背景误差成为主要误报来源，再评估地面参考站或停驻时的风测组件。

## 6. 传给 BN 的信息

每个观测都要回答“哪台设备、在哪段线路的哪个位置、什么时间、什么模式、测了什么、测量是否可信”。至少保留：

- `observation_id, sensor_id, asset_id, installation_id`。
- `observed_at, received_at, window_start, window_end`。
- `measurement_kind, value/features, unit, sampling_rate_hz`。
- `device_mode, rotor_state, clamp_state, charging_state`。
- `quality_flags, calibration_version, baseline_version, synthetic`。
- 图像/热像附 `image_ref, target_id, view_pose` 和测温参数；定位附坐标基准与定位质量。

实际采样率和上报率分开。振动频谱需要足够高的原始采样带宽及抗混叠处理；若仅拿到低频摘要，不能虚构高频波形或频带能量。首版可沿用设计稿的示例时间窗，但窗口长度是演示参数，需要真实带宽与异常时标确认。

BN 优先使用条件基线残差、持续性、视觉证据和质量状态。振动与倾角可能同源，应作为联合机械证据或通过共同原因建模；连续图像、同一时窗和同一天气过程也不能重复当作独立确认。原始温度与由它计算的残差同样不独立。

区分“温度异常”“机械异常”“带电状态”“传感器/安装问题”，不要压成一个无原因的异常标签。异常输出是核查证据；不直接声称确定故障原因或未来必然故障。

## 7. 下一轮最需要确认的硬件信息

1. 现有温度究竟测导线、空气、设备壳体还是内部电子器件？已有倾角坐标系与安装点是什么？
2. 本次是否能导出官网所述 RGB 和线路电流？所谓电压是实际量值还是带电状态代理？
3. 每通道的单位、精度、范围、采样带宽、上报频率、延迟及缺失/质量标记是什么？
4. 飞行、夹持建立、稳定停驻、充电过程中，哪些测量被厂商认可有效？
5. 平台是否已输出标定弧垂/净空？如有，其参考坐标、位置、误差与覆盖范围是什么？
6. 250 g 是否包含全部结构与线束？可用接口、持续/峰值供电、安装空间和可复用计算资源是什么？

可以先用明确的假设数据完成软件演示，同时把这些缺项保留在数据契约中。实物采购应等第1、2、6项明确后，再按主案例决定是否需要额外器件。
